# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release
- Oh My Zsh + Powerlevel10k installation (lean/classic/rainbow themes)
- Zsh plugins: autosuggestions, syntax-highlighting, completions, fzf-tab, vi-mode
- Modern CLI tools: eza, bat, fd, ripgrep, zoxide, btop, delta, lazygit, fzf
- Shell configuration: .zshrc, .p10k.zsh, .gitconfig
- Opencode configuration: theme, keybindings, shell integration
- Nerd Fonts: MesloLGS NF, JetBrainsMono NF
- Multi-platform support: Linux, macOS, Windows, Android/Termux
- Docker support with multi-arch images
- Universal installer script
- Idempotent installation with rollback
- Dry-run mode for preview
- Comprehensive environment detection (WSL, Termux, Container, etc.)
- Cross-compilation for amd64/arm64
- GoReleaser for automated releases
